# NHS Patient Operations & No-Show Analytics

## Project Overview

This project simulates a real-world healthcare analytics engagement for a fictional NHS Trust. The objective is to analyse patient appointment data to identify operational inefficiencies, understand the causes of missed appointments (no-shows), and provide actionable recommendations that improve patient attendance, optimise resource utilisation, and support data-driven decision-making.

The project demonstrates an end-to-end analytics workflow, including business requirements gathering, data modelling, synthetic data generation, SQL analysis, exploratory data analysis (EDA), dashboard development, and executive reporting.
